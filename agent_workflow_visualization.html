✈️ Flight Assistant Engine

Abstract ReAct Agent Loop

The system loops continuously, generating travel thoughts and dynamically executing flight tools before outputting the passenger's final booking confirmation.

Input
Traveler Request
User asks to find best flights (e.g., from CDG to AUS on 2026-03-03), validate passenger Nguyen Van A, hold seats, and print receipts.
→
Entry
Initialize Booking state
run(user_input) boots context, initializes telemetry tags, and registers the traveler's active session profile.
→
Model
Flight Planner Engine
LLM reasons: "I must search/compare flights first to extract a valid booking token before executing holds or invoices."
Decision
Action Parser
Checks if model output matches tool formats like compare_flights(...) or has reached the final confirmation.
→
Resolve
Dynamic Tool Resolver
Matches action name (e.g., compare_flights) against the flight comparison, hold, and invoice modules.
→
Execute
Execute Flight Tool
Runs target function with auto-coerced types (converting string counts to ints, prices to floats, and statuses to bools).
Observation
Travel Observation
Captures the comparative matrix, profile validation success, hold reference codes, or drafted invoice dictionary.
→
Continue
Chain Travel Actions
LLM inspects observation: "Flight hold created with HOLD-E5A2B9C1. Next, I must call generate_invoice to draft the ticket invoice."
→
Output
Booking Confirmation
Exits loop. Delivers the hold code, booking reference BK-2F9A1B8C, and path to the newly saved Helvetica PDF invoice on disk.

🚀 Combined Booking

Concrete 5-Step Pipeline Flow

How the ReAct Agent chains five distinct toolsets in sequential order to resolve a nomad traveler's request in a single loop.

1
Flight Selection & Comparison
Searches routes and returns a ranked recommendation matrix using duration and comfort metrics.
compare_flights
2
Declarative Profile Validation
Gathers name, email format, and phone structures, validating traveler details under declarative schemas.
collect_personal_info
3
Simulated Hold Allocation
Locks seat allocation temporarily for 15 minutes, returning a simulation code (e.g. HOLD-E5A2B9C1).
hold_flight
4
ASCII Receipt Drafting
Compiles fares, computes taxes, registers a 5% service surcharge, and formats a textured text-invoice.
generate_invoice
5
Helvetica Confirmation Export
Generates a highly readable confirmation PDF in the workspace for nomad offline receipts.
generate_invoice_pdf
